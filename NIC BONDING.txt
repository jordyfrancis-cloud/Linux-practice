NIC bonding 
 
NIC bonding is used to combine two or more physical network cards into a single virtual network connection


*	Create a Bond Interface File

       vi /etc/sysconfig/network-scripts/ifcfg-bond0
  
*      Add the following parameters
    
        DEVICE=bond0	
      	TYPE=Bond
	NAME=bond0
	BONDING_MASTER=yes
	BOOTPROTO=none
	ONBOOT=yes
	IPADDR=192.168.1.80
	NETMASK=255.255.255.0
	GATEWAY=192.168.1.1
	BONDING_OPTS="mode=5 miimon=100"

* Save and exit the file


* Edit the First NIC File (enp0s3)

	vi /etc/sysconfig/network-scripts/ifcfg-enp0s3
	Delete the entire content
	Add
	TYPE=Ethernet
	BOOTPROTO=none
	DEVICE=enp0s3
	ONBOOT=yes
	HWADDR="MAC from the ifconfig command"
	MASTER=bond0
	SLAVE=yes

* Save and exit 

* Edit the Second  NIC File (enp0s8)

	vi /etc/sysconfig/network-scripts/ifcfg-enp0s3
	Delete the entire content
	Add
	TYPE=Ethernet
	BOOTPROTO=none
	DEVICE=enp0s8
	ONBOOT=yes
	HWADDR="MAC from the ifconfig command"
	MASTER=bond0
	SLAVE=yes

* Save and exit 



* Restart the network service
	systemctl restart network

* Test and verify
	ifconfig
* Use the command to view bond interface settings like bonding mode and slave interface
	cat /proc/net/bonding/bond0
