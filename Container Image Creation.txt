Container Image Creation 

We are going to create container image using podman as user jordy.
We will build a container image named web_image using the container file located at http://repo.rhcsa.home/containers/Containerfile.

We will deploy jordy_web with the following:

*Map host port 8000 -> container port 80.
*Map the host directory /opt/user_files to container directory /opt/userfiles. Files should be accessible
*Configure the container as a systemd service to start on boot
